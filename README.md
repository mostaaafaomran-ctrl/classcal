# ClassCal

**Turn your typed university timetable into an .ics file for Google or Apple Calendar. Arabic and English. Free, private, no signup.**

**[Open live](https://mostaaafaomran-ctrl.github.io/classcal/)**

## English
Type one class per line, for example `Sun 09:00-10:30 Data Structures @ Hall 3`. Pick the semester dates, download `timetable.ics`, and import it. Each class becomes a weekly repeating event until the semester ends.
- Days in English (Sun, Monday) or Arabic (الأحد, سبت). Arabic digits work.
- Skip holidays with a list of dates.
- Optional reminder 15 minutes before each class.
- Times are saved as local times without a timezone, so they appear at the same clock time on your calendar.
- Nothing is uploaded. Your timetable is kept in your browser only.

Photo and PDF import are not supported yet.

## بالعربي
اكتب حصة في كل سطر زي `الأحد 09:00-10:30 هياكل بيانات @ قاعة 3`، اختار بداية ونهاية الترم، ونزّل ملف `timetable.ics` وارفعه على Google Calendar أو تقويم الآيفون. كل حصة بتتكرر أسبوعيًا لحد آخر الترم. تقدر تتخطى الإجازات وتفعّل تذكير قبل الحصة بـ15 دقيقة. مفيش حاجة بتتبعت لأي سيرفر.
